# The only release on PyPI, vis-evaluator 0.0.3, has a broken evaluate.py: it calls
# surface_form_check() without importing it, so every run dies on the first query with
#   NameError: name 'surface_form_check' is not defined
# The GitHub main branch fixes that, and its pyproject correctly pins `langchain<1`
# (the PyPI wheel leaves langchain unbounded, which pulls in LangChain 1.x and breaks
# `import viseval` with "No module named 'langchain.schema'").
#
# Needs git on PATH. If you don't have it, download the repo as a ZIP, unzip it, and
# run `pip install .` inside — then `pip install "langchain<1"` yourself.
